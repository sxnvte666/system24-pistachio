# system24-pistachio
Discord theme based on system24 with colors changed.

It's just color scheme change to make discord fit my linux "rice"
That's why only the "base" file has changed

# Usage (betterdiscord/vencord or any other client)

## quickcss 

```css
@import "https://raw.githubusercontent.com/sxnvte666/system24-pistachio/refs/heads/main/system24-pistachio.css"
```

# .css file
- Download the `system24-pistachio.css`
- Drag .css file into your client themes directory
